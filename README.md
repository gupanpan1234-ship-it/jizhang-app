# 家庭记账 App

简洁的家庭记账 PWA 应用，支持 OPPO Find N6 等手机添加到主屏幕使用。

## 功能

- 📝 收支记录：13 个支出大类 + 子分类，3 个收入分类
- 📊 数据图表：饼图（分类占比）、柱状图（月度对比）、折线图（消费趋势）、热力图（全年概览）
- 🎯 预算管理：为每个分类设置月度预算，超支提醒
- 📱 PWA 支持：可添加到手机主屏幕，离线使用
- 📤 数据备份：支持导出/导入 JSON

## 使用

### 1. 安装依赖

```bash
cd jizhang-app
npm install
```

### 2. 生成图标

在浏览器中打开 `public/generate-icons.html`，点击按钮下载图标，放到 `public/` 目录下。

### 3. 启动开发服务器

```bash
npm run dev
```

用手机浏览器访问电脑 IP:5173（确保同一 WiFi）。

### 4. 构建部署

```bash
npm run build
```

将 `dist/` 目录部署到任意静态托管服务（Vercel、Netlify、GitHub Pages 等），然后用手机浏览器打开网址，选择"添加到主屏幕"。

### 5. 家庭共享（可选）

需要 Supabase 账号：

1. 在 [supabase.com](https://supabase.com) 创建免费项目
2. 在 SQL Editor 中运行 `supabase-migration.sql`
3. 复制 `.env.example` 为 `.env`，填入 Supabase URL 和 anon key
4. 重新构建部署
